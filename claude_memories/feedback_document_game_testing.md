name: Document game testing/experiments immediately
description: Always log Dune Awakening (and other game) testing sessions, experiments, and findings to both the session log AND the relevant reference file before the conversation ends
type: feedback
---

When testing game mechanics (crafting bonuses, drop rates, damage values, etc.), document findings immediately — don't wait until end of conversation.

**Why:** User has been burned multiple times by test results not being saved. Lost the 30% bonus chance testing data from a Dune Awakening session because it wasn't logged to session log or reference file.

**How to apply:** During ANY game testing/experimentation conversation:
1. Log what's being tested to the session log at the START
2. Update the relevant reference file with results AS they come in
3. Don't rely on end-of-conversation logging — it gets missed
