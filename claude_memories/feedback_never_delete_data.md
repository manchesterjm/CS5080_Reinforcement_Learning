Never delete or overwrite existing data in project files like TRAINING_PLAN.md. These are data records, not status pages.

**Why:** Data must be preserved at all costs. Eval trajectories, run histories, checkpoint info, and conclusions from specific training phases are irreplaceable observations. Summarizing over them destroys information.

**How to apply:** When updating these files, only append new information or update a status header. Never remove existing entries, metrics, eval trajectories, or historical notes — even if they seem outdated or redundant.
