Never give vague estimates or guesses when real data can be computed. Josh is a data person — pull actual numbers, calculate from logs, measure from timestamps.

**Why:** Josh found it unacceptable when given a hand-wavy "maybe an hour or two" estimate for training completion instead of computing the actual pace from log data.

**How to apply:** Whenever asked about timing, performance, or any quantifiable metric, compute it from available data (logs, metrics files, timestamps, etc.) before responding. If no data is available, say so — don't fill the gap with a guess.
